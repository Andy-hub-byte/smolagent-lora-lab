导入外部模型

        
把已经下载好的模型加进来，之后训练和对话都能直接选它。支持三种方式，任选其一。

      


      

        

          
方式一 · 本机文件夹

          
填写模型文件夹的绝对路径（在运行本服务的电脑上），会拷贝到项目的 models/ 目录。适合模型已经在你电脑硬盘里的情况。

          
          
          
          
        


        

          
方式二 · Hugging Face / ModelScope 仓库

          
填写仓库 ID 直接下载到 models/ 目录。国内推荐魔搭；Llama 等门控模型需先在 HF 官网同意协议并运行 hf auth login。支持内置短名（如 qwen2.5-1.5b）。

          
          
          
          
          
        


        

          
方式三 · 网页上传

          
适合平板 / 手机：直接把模型文件（可多选，或打包成一个 zip）传上来，自动落到 models/ 目录。
