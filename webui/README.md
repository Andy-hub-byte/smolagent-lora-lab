# Web 微调工作台（webui/）

把 `train_lora.py`（训练）、`agent.py`（模型对话）和 `import_model.py`（导入外部模型）
包装成一个**本地网页界面**：不用记命令、不用看日志刷屏，点表单就能微调模型、
实时看 loss 曲线、和模型对话。**界面支持中英一键切换**（左下角 🌐 按钮，按浏览器语言自动初始化）。

> 所有数据只在你自己的电脑里处理，不上传任何服务器。
> / All data stays on your machine — nothing is uploaded.
>
> **界面风格对标 LM Studio 电脑版**：左侧图标导航栏 + 深色主题；「💬 模型对话」放在首位，
> 聊天页为 LM Studio 同款布局——顶部模型选择器、中间对话记录（用户消息气泡 + 运行日志）、
> 底部圆角输入框（回车发送 / Shift+Enter 换行）、右侧参数面板（⚙ 参数按钮开关）。

## 一、启动（30 秒）

```bash
# 项目根目录下（smolagent-lora-lab/）
python webui/app.py
```

看到 `访问地址: http://localhost:7860/` 后，浏览器会自动打开。
手机 / 平板想访问，加 `--host 0.0.0.0`，然后用同一 WiFi 下访问 `http://<电脑IP>:7860`。

**Windows 用户**：双击 `启动WebUI.bat`（项目根目录）。

**依赖**：只需要 `pip install flask`（其余训练依赖见项目根 requirements.txt）。
端口被占用时换一个：`python webui/app.py --port 7861`。

## 二、左侧导航怎么用（LM Studio 风格）

### 🩺 环境体检
自动检测 Python 版本、PyTorch/Transformers/PEFT/TRL/Datasets/smolagents 是否安装、
有没有 NVIDIA 显卡（CUDA）与显存，并给出操作建议（缺什么装什么）。

底部还有**「生成微型模型」**：构造一个约 10MB 的随机权重 Qwen（真实 tokenizer），
用来在没有网络、没有显卡的电脑上完整跑通「训练→适配器→对话」全链路。
**它只是链路自检用品，生成的内容没有意义，不要当真模型对话。**

### 📥 模型导入
把外部模型加进 `models/` 目录，之后训练和对话都能直接选它。三种方式任选其一：

| 方式 | 适合场景 |
|---|---|
| **本机文件夹** | 模型已经在你电脑硬盘上（填绝对路径，拷贝进 `models/`） |
| **HF / 魔搭仓库** | 填仓库 ID 直接下载（国内推荐魔搭；Llama 等门控模型需先 `hf auth login`） |
| **网页上传** | 平板 / 手机：多选文件或打包成一个 zip 传上来 |

导入时自动校验 HuggingFace 格式（`config.json` + `.safetensors/.bin` 权重），
不完整的目录会在表格里标红。列表右上角可**搜索过滤**；表格里可**用作基座**
（一键跳到训练页并选好它）或**删除**。

### 🚀 训练
左边表单 = 原来 `train_lora.py` 的一堆参数，右边 = 实时日志 + loss 曲线。

1. **模型**：选来源（魔搭 / HuggingFace / 本地路径），选基座。
   本地路径模式配合上面生成的微型模型，可完全离线跑通。
2. **数据集**：合并 `datasets/` 全部 jsonl，或只用其中一个。
3. **LoRA 参数**：秩 r / alpha / dropout（新手用默认 16 / 32 / 0.05 即可）。
4. **训练超参**：batch、梯度累积、学习率、轮数、固定步数、序列长度。
   - `固定步数 = -1` 表示按轮数算；填正数则到步数就停（适合先试跑）。
   - 表单下方实时显示**等价命令行**——照着抄就能在终端复现同样的训练。
5. 点 **🚀 开始训练**：日志逐行滚动，loss 曲线实时绘制，随时可 **⏹ 停止**。
6. 断点续训：勾选后从输出目录里最新快照继续（对应 `--resume`）。

训练完成后，适配器保存在表单里填的**输出目录**（默认 `lora_output/`，可在「产出管理」看到）。

### 💬 模型对话（对标 LM Studio 聊天页）
两种用法都在这里，**零基础友好**：

1. **顶部选模型**：下拉里分组列出——本地模型（`models/` 目录）、
   在线模型（自动下载）、Ollama 本地服务、手动输入路径。
2. **顶部选适配器（可选）**：
   - 训练过的模型 → 选训练产出（适配器是微调产生的「补丁」）；
   - **刚导入、没训练过的模型 → 选「不使用适配器」，原版模型直接对话**。
3. **底部输入框**填任务内容，**回车发送**（Shift+Enter 换行）。
   你的消息以蓝色气泡显示，下方实时显示模型的思考与工具调用；运行中点「⏹ 停止」随时结束。
4. 右侧 **⚙ 参数** 面板：单步生成上限、Agent 最大步数；
   难懂的路径输入（手动模型路径 / Ollama 地址等）全部收进面板里的「高级设置」折叠区。

日常使用只需要点两个下拉、打一串字、按回车——和 LM Studio 聊天一样。

### 📚 数据集
列出 `datasets/` 下所有 jsonl 的条数与大小，点「预览」看前 5 条原始内容。

### 📦 产出管理
列出 `lora_output/` 等目录下的适配器与 `checkpoint-*` 快照（大小、时间），
一键「用作适配器」填入模型对话页。

## 三、断线续跑（关屏幕挂机）

训练 / 对话任务跑在**独立进程组**里，与服务器、终端、控制台全部脱钩：

- 关掉网页 → 任务继续跑（日志写在 `webui/runtime/`，重开网页自动重连）；
- 关掉终端 / 直接强杀服务器 → 任务**继续跑**；
- 重新运行 `python webui/app.py` → 启动横幅提示「★ 已接上仍在运行的作业」，
  loss 曲线从日志自动重建，停止键可正常结束它。

命令行用户挂机可用系统自带手段：`nohup python train_lora.py ... &`、`screen` 或 `tmux`。

## 四、WebUI 与命令行的对应关系

| 界面操作 | 等价命令 |
|---|---|
| 导入模型（本机路径） | `python import_model.py /path/to/model` |
| 导入模型（仓库） | `python import_model.py <repo-id> --source modelscope` |
| 开始训练（表单全填） | `python train_lora.py --model-source ... --model ... ...` |
| 停止训练 | 向训练进程组发 SIGTERM（等价 Ctrl+C 的安全退出，只停训练不停服务器） |
| 模型对话（选模型+适配器） | `python agent.py --mode C --model-path ... --adapter ...` |
| 生成微型模型 | `python make_tiny_model.py --output ...` |

界面上每个操作都会把等价命令打印在日志第一行，方便学习与复现。

## 五、常见问题

**Q：点了开始训练没反应 / 立刻报错？**
看右侧日志末尾。最常见两类：依赖没装（去环境体检页看红字）、
CPU 上选了 7B/14B 被主动阻止（换 ≤4B 或加「硬件不足仍强制启动」）。

**Q：点了「停止」页面卡住 / 之后没反应？**
早期版本的停止键会误杀服务器进程，已修复：现在停止只结束训练本身
（按钮会先变「停止中…」，约 5 秒仍不退会强制结束），服务器始终存活。

**Q：训练能中途关页面 / 关终端吗？**
能。任务在独立进程组中运行，关网页、关终端、甚至服务器崩溃都不影响任务继续；
重新打开本程序会自动接上（见上面「断线续跑」）。

**Q：loss 曲线是平的？**
先用 `固定步数 = 3~10` 试跑确认链路，再看学习率是否过大/过小。
微型随机权重模型的 loss 本来就没有下降意义——它只验证流程。

**Q：没训练过的模型能直接对话吗？**
能。模型对话页第二步选「不使用适配器」即可（相当于 `agent.py --mode C --model-path ... `，
不挂任何适配器）。

**Q：想给数据集加自己的数据？**
在 `datasets/` 放 jsonl，每行一条 `{"messages": [{"role":"user",...},{"role":"assistant",...}]}`，
刷新网页即可在数据集页看到（参考 `dataset_custom_sample.jsonl`）。
